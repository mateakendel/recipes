Data analytics and machine learning project

Recipe recommendation system

This application allows users to create, search, rate and view recipes. User activity is collected through Kafka, stored in MongoDB and Redis, indexed with Elasticsearch, and used to train a Naive Bayes model for personalized recipe recommendations.
